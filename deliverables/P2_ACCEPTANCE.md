# P2 实施与验收报告

日期：2026-11-14（Asia/Shanghai）

## 已交付

- API 启动和每轮采集后自动进行规则初筛；不改变既有 n8n 采集接口，自动采集不会触发模型。
- 保守的疑似事件归并：标题相似、版本数字一致、48小时内、否定线索不冲突；固定锚点防止连锁合并，原始出处全部保留。
- 可解释的时效、受众相关、变化线索、演示潜力、可追溯和材料完整度分；研究材料默认降低优先级，缺失/未来/过期日期不自动推荐。推荐不凑数。
- 中文选题工作台：推荐/全部/已选/忽略筛选、标题搜索、分页、人工选择与恢复、Markdown导出。
- 可选手动模型分析：中文选题名、摘要、理由、角度、待核实项、引用材料ID；只读有限公开网页片段或RSS摘要回退。
- OpenAI、Anthropic、Gemini、DeepSeek、Qwen 五类请求适配；只向固定官方主机发送密钥，不跟随重定向，不自动重试付费请求。
- 持久化请求预算和缓存：北京时间每天最多12次，失败/中断计入；单选题至多两篇片段、每篇3500字符、总提示材料12000字符以内、输出1600 tokens以内。不是金额上限。
- P1→P2 代码升级保护与 schema2→3 自动备份迁移。已有配置、数据库、人工决策及工作流持久化方式保留。

## 使用边界

规则初筛是启发式，不能保证挑中全部重要消息；默认保留英文原题。疑似归并存在漏合并和误合并可能，未提供人工拆分。网页片段不一定是完整正文。模型JSON和引用ID校验不等于语义核实，所有结论仍需人工检查。

模型参考分不会自动改变规则推荐排序，避免把未经验证的模型判断当作事实。失败/缺少token用量不等于零成本。模型分析仍由人工点击；完整抖音口播、小红书图文稿、视频制作和社交平台发布尚未实现。

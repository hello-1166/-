# IndexTTS 本地配音接入

适用于现有 Radar P5 / IndexTTS-2.5-fast（上游源提交 d9e41aac89fd00b3d71497fddb287b7f24613712）。不下载模型，不调用付费接口，不发布内容。

## 安装与使用

1. 在原项目 `F:\github1113\AI_Frontier_Radar_P0` 应用 P6 定向升级，再执行 `scripts/start_p0.ps1` 重建 API。
2. 执行 `scripts/setup_indextts_bridge.ps1`。脚本备份 WebUI，再加入本地接口。已有上传兼容补丁保留；未知布局或自定义接口文件会停止而非覆盖。
3. 在原 IndexTTS 窗口按 Ctrl+C 停止旧实例，再在原 Radar 项目运行 `scripts/start_indextts.ps1`。保留该窗口，不再开第二个模型实例。
4. 打开 http://127.0.0.1:7860，上传自己的或有权使用的清晰参考音频，先试听，再保存预设，例如 `AI前沿雷达男声`。8GB 显存使用跟随音色、参考音频或向量情绪模式；本桥不启用占用额外显存的情绪文本模型。
5. 在另一个 PowerShell 窗口进入原 Radar 项目，运行 `scripts/video_worker.ps1`，保留窗口。只开一个 worker。不同安装目录可传 `-IndexTTSRoot '你的目录'`；端口改变可传 `-IndexTTSUrl 'http://127.0.0.1:你的端口'`。
6. 打开 http://localhost:8000/videos，选择原视频任务，在“本任务配音设置”中选 **IndexTTS 本地音色预设**，填写刚才保存的预设名称，保存设置。已有配音和普通预览的引用清空，旧文件留在原任务目录；FredTalk 旧成片保留。
7. 点击“素材准备完毕，加入自动队列”。助手逐段配音、标准化 WAV、导入配音，然后启动原有 FFmpeg 视频合成。第一次模型推理可能较慢，窗口每段显示进度；每段最多等待10分钟，不会无限等待。
8. 完整试听预览。若需要新的 FredTalk 动效成片，准备新的制作包后再走 FredTalk 制作及回传；普通合成不会自动修改 FredTalk 旧成片。

## 兼容性与空间

- Windows 系统语音及本人录音继续可用。未更改配音设置的旧任务可继续导入原配音包。
- 新任务和旧任务均可选择本地配音；更换预设请先取消队列。重新保存配音设置会生成版本标识，旧包不能覆盖新设置。已取消或重新入队的 IndexTTS 任务拒绝旧助手导入、合成及错误回写。
- 配音按最多180字的完整语句生成，避免按22字字幕行反复推理。字幕依据句子实际时长拆分，句内按字数估算，并非逐字强制对齐；英文缩写、数字及停顿请试听。
- Windows 助手复用 IndexTTS 环境中的 gradio_client、soundfile、numpy、scipy，不再加载模型、不额外安装 PyTorch。Docker API 不需要访问 Windows F 盘或 GPU。
- 成功获取的 IndexTTS 桥接临时 WAV 会删除；客户端临时目录也自动清理。异常退出可能留下 `IndexTTS/outputs/radar-api` 的 WAV，确认不用后可手动删除。Gradio 自身的系统临时缓存也可能存在。模型权重不会每次生成重复下载。
- Radar 保存的音频、视频和升级备份会随制作期数增加；旧文件不会自动删除。不能把 F 盘存储占用与 GPU 显存、内存混为一谈。
- 配音内容、参考音频及预设不上传云端；服务仅允许回环地址、禁止 Gradio share。生成只使用已确认稿件，不保证新闻真实性和音色自然度。

## 排障与回退

- 预设找不到：先在 IndexTTS 保存，确认名称完全一致；不要填写文件路径。预设存放在 `outputs/presets/<名称>/preset.json`，参考音频须随预设保存在该目录内。
- `radar_synthesize` 不存在：确认桥接已安装，旧 WebUI 已关闭，并使用新的 `start_indextts.ps1` 启动、刷新页面。
- 端口已占用：停止旧实例，不要同时开两个模型。
- 显存不足：关闭其他占用显存的软件，使用 fp16，避免情绪文本模型和同时渲染其他 GPU 项目。
- 升级停止提示本地文件改动：没有应用任何文件，保留错误信息供核对，不要强行覆盖。
- 回退接口：停止 IndexTTS，用 `webui.py.radar-backup-*` 恢复对应备份并移除 `radar_indextts_api.py`。Radar 切回 Windows/录音即可继续工作。升级器生成 `backups/p6-code-*` 并记录变更文件列表。

## 验证范围

云端验证涵盖接口、配音包版本校验、取消、回环地址限制、预设目录边界、API扩展安装幂等、参数映射、音频重采样、脚本语法和升级保留行为。云端无 NVIDIA GPU，未声称完成用户 Windows/RTX4060 上的真实模型端到端合成；首次本机生成是最终环境验证。

# P3 内容策划台：Windows 升级与使用

本版在 P2.1 上增加本地内容策划台。已有的新闻、分类、已选题和 n8n 工作流沿用。无需购买模型 API；导出 Markdown 材料包交给现有 ChatGPT Plus。

## 升级

保持 Docker Desktop 运行。将 P3 ZIP 解压到独立新目录，例如 `F:\github1113\AI_Frontier_Radar_P3`，找到同时包含 `scripts`、`src`、`docker-compose.yml` 的文件夹，在这里打开 PowerShell。

每条命令单独运行，确认完成后再运行下一条：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

```powershell
.\scripts\upgrade_p3.ps1 -ExistingProjectPath "F:\github1113\AI_Frontier_Radar_P0"
```

升级脚本先校验整个文件清单，遇到未知的本地代码修改会停止且不写入。成功时备份被替换的旧代码，保留 `.env`、`data`、`logs` 与 n8n 卷。它不执行删除容器或卷的操作。

看到 `P3 code installed` 后，切回原项目目录：

```powershell
cd "F:\github1113\AI_Frontier_Radar_P0"
```

```powershell
.\scripts\start_p0.ps1
```

必须从原目录启动。首次运行会将 SQLite 从版本 4 升到 5，先在 `data/backups/radar-before-p3-*.db` 备份旧数据库，再添加策划表。不要将旧数据库覆盖到正在运行的服务。

启动通过后打开：<http://localhost:8000/plans>。新闻收件箱、选题工作台的顶部也有“内容策划台”入口。页面未更新时使用 Ctrl+F5。

## 制作第一期

1. 点“新建内容策划”。系统读取本地数据库中的已选题，无需重新导入之前的选题文件。
2. 单条视频勾选一个事件，周报可勾选多个事件（每期最多 30 个）。填写本期名称、选择形式，点击创建。
3. 填目标观众、本期主旨、开场问题、内容提纲。检查来源、发布日期、费用、开放地区与账号条件。
4. 每个事件可写角度、核实情况和画面备注，支持上移、下移、移出本期及从已选题补充材料。移出不会删除原始新闻或取消已选题。
5. 点“保存策划”后再离开。页面提示未保存修改；多页面发生冲突会阻止覆盖，先复制未保存文字再刷新。
6. 点“保存并导出创作材料包”，上传所得 `radar-plan-*.md` 到现有 Plus，请其完善稿件。材料包包含来源快照、日期、摘要、分类、原有待核实项及你填写的内容。
7. 将修改后的口播和小红书草稿粘贴到“口播与图文草稿”，保存，人工设置制作进度。

来源快照在加入策划时保存，后续采集和重新初筛不会改写已保存的本期材料。再次核实时应打开原文检查是否更新。制作进度和分类标记不等于事实核查结论；选择“已发布”只是本地记录，不会向平台发送内容。

## 边界

本版提供人工编排与草稿保存，不会自动总结全文、生成事实结论、调用模型、录制视频或发布到平台。它不自动判断“第一期应该选哪条”；可以将选题文件交给 Plus 辅助选择。

## 回退

代码备份在原项目的 `backups/p3-code-*`。数据库升级前备份在 `data/backups`。回退前先停止服务并备份当前代码、数据库和 `.env`，再同时恢复匹配的旧代码及旧数据库；旧版本不识别版本 5。回退旧数据库会失去备份之后新建的策划和新闻，因此应先导出需要保留的策划。不要删除 n8n 卷。

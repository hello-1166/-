# 配音包句号空片段修复

适用于本期任务中 s02-c007.wav 为单独句号且包含零音频帧的问题。脚本严格检查任务、片段与空 WAV 原始字节，再复制 ZIP，仅将该片段替换为 120ms、24kHz、16位单声道静音。原 ZIP、清单与其他文件不变。此为一次性结果包修复，不改变已部署的系统分句逻辑。

在 Windows PowerShell 中运行脚本，选择原始 voice-result-b70fd5f1.zip，再将生成的 voice-result-fixed-*.zip 导入原视频任务。不要重新创建视频任务。PowerShell 7/Linux 实际处理后内容与 Python 修复包一致；现有导入器接受三段音频，合计110.907秒，原包导入复现400。Windows选择文件对话框未在云端执行。

仓库仅包含修复代码与说明，不包含用户配音。
